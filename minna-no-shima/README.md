# 🏝️ みんなの島

ブラウザで遊べる小規模MMO。島で木と石を集め、中央の「みんなのタワー」に納品して全員でタワーを高くします。

> **現在の状態：ひとり用（クライアントのみ）**
> サーバー（Colyseus）はまだ実装していません。サーバー権威のロジックはブラウザ内の「ローカルサーバー」として動いており、データは localStorage に保存されます。

## 遊び方

```bash
cd minna-no-shima/client
npm install
npm run dev        # http://localhost:5173
```

| 操作 | スマホ | PC |
|---|---|---|
| 移動 | 地面をタップ | タップ／クリック、矢印キー・WASD |
| 採取 | 木・岩をタップ（近づいて自動で続けて採取） | クリック、またはスペースキー |
| 納品 | タワーをタップ | クリック、またはスペースキー |
| スタンプ | 下のボタン（8種） | 同じ |

- 採取は1回ごとに3秒のクールダウン。持ち物は最大20個。
- 木1個＝タワー10cm、石1個＝20cm。
- 節目：100m 東の森／500m 北の岩山／1000m 西の小島（それぞれ橋が開通）、2000m 夜空の花火、5000m 虹のアーチ。
- `?dev` を付けて開くと **T キーでタワーを +50m**（節目の演出確認用、保存はされません）。

## 構成

```
client/
├─ src/core/      # サーバー権威ロジック（Phaser・DOM 非依存。後でサーバーと共有する）
│  ├─ world.ts    #   移動・当たり判定・採取・納品・レート制限
│  ├─ map.ts      #   シードから島を決定論的に生成（地形データを送らずに済む）
│  ├─ protocol.ts #   メッセージ型（クライアントは「意図」だけ送る）
│  └─ ...
├─ src/net/       # Backend インターフェース、ローカル実装、補間
├─ src/scenes/    # Phaser の描画
├─ src/ui/        # HUD（タワーの高さ、ランキング、シェア、スタンプ）
└─ test/          # vitest
```

`Backend` インターフェースの裏側を `LocalBackend` から Colyseus 版に差し替えれば、マルチプレイになる設計です。

## 開発

```bash
npm test           # ロジックのユニットテスト
npm run build      # 型チェック + 本番ビルド（dist/ を静的ホスティングに置けば動く）
```
