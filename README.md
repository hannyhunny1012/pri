# バンド予定帳

バンドメンバー4人でリハ・ライブなどの予定と、各自の空き状況（○△×）を共有するカレンダーです。

公開版: https://claude.ai/artifact/N7nAv4VT8r3CbRMAC71A9h

## できること

- バンド名と4人のメンバー（名前・パート）を登録
- 日付ごとに各メンバーが ○（空いてる）／△（調整すれば行ける）／×（無理）を入力
- 全員が ○ の日はカレンダー上で緑色に表示
- 「空きをまとめて入力」で、日付をタップするたびに自分の印を切り替え
- 予定（リハ／ライブ／録音／MTG／その他）を時間・場所・メモ付きで登録・編集・削除
- 「これからの予定」で直近の予定を一覧表示

## データの保存先

- claude.ai の Artifact として開いた場合は、共有データベースに保存され、メンバー全員の画面にリアルタイムで反映されます。
- それ以外（`index.html` を直接ブラウザで開いた場合など）は、そのブラウザの localStorage にだけ保存されます。

## メンバーと共有する方法

公開版のページ右上の共有メニューから、3人のメンバーをメールアドレスで「編集者」として招待してください。
閲覧者として招待した人やリンク共有で開いた人は、予定を見ることはできますが書き込めません。

## ファイル

- `index.html` — アプリ本体（HTML・CSS・JavaScript を1ファイルにまとめたもの）
