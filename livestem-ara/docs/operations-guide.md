# 運用ガイド

LiveStem ARA を使った共同制作の、送る側・受け側の設定をまとめます。

> DAWのメニュー名と場所はバージョンによって変わります。下の記述は Logic Pro 11／Studio One 7 を想定した目安です。実機で違っていたら、このファイルを直してください。

## 1. 全体の流れ

1. 送る側：自分の担当トラックを、決めた形式で共有フォルダに書き出す（毎回同じファイル名で上書き）。
2. Syncthing：共有フォルダを相手のPCへ同期する。
3. 受け側：LiveStem ARA が更新を検知し、0.5〜1秒ほどで新しい内容を鳴らす。

## 2. 事前に決めること

| 項目 | 決めること | 例 |
| --- | --- | --- |
| スロット | 1人あたりの共有トラック数と名前 | 8本：`drums`, `bass`, `gtr1`, `gtr2`, `keys`, `vox`, `fx`, `bus_rev` |
| ファイル名 | `<担当者>_<スロット名>.wav` | `alice_gtr1.wav`, `bob_bass.wav` |
| 書き出し範囲 | 曲頭（小節1）から「曲の長さ＋余白」の固定長 | 小節1〜小節121（曲は小節113まで、余白8小節） |
| テンポ | BPM・テンポチェンジ・拍子変更を両者で完全に一致させる | 120 BPM 固定、4/4 |
| 形式 | WAV、48kHz、32bit float | |

固定長を後から伸ばす場合は、全員で同時に変えてください。受け側のクリップより短いファイルは、足りない部分が無音になります。長いファイルは、受け側のクリップの元の長さを超える部分が使われません。

## 3. Syncthing の設定例

1. 両方のPCに Syncthing をインストールし、デバイスIDを交換して相互に追加する。
2. 共有フォルダを1つ作る（例：`~/LiveStem/曲名/`）。フォルダIDは両者で同じにする。
3. フォルダの設定：
   - **フォルダの種類**：両者「送受信」。自分の担当ファイルしか書き込まない運用にする。
   - **変更の監視**（Watch for Changes）：有効。更新が数秒で伝わります。
   - **ファイルのバージョン管理**：任意。過去の版を残したいなら「シンプル」で数世代。
   - **権限を無視**：有効（macOS と Windows の混在時）。
4. 無視パターン（`.stignore`）の例：
   ```
   (?d).DS_Store
   (?d)Thumbs.db
   *.tmp
   ```

Syncthing は受信したファイルを一時ファイル（`.syncthing.<名前>.tmp`）に書いてから名前を変えるので、受け側のプラグインが途中までのファイルを読むことはありません。念のためプラグイン側でも、サイズと更新時刻が500ms変化しなくなるまで待ってから読みます。

**注意：書き出し先を共有フォルダに直接指定すると、DAWが書いている途中の状態で同期が始まることがあります。** Syncthing は書き込み中の変化を検知して同期をやり直すので、最終的には完成版が届きます。気になる場合は、いったん別フォルダに書き出してから共有フォルダへコピー（上書き）してください。

## 4. 送る側：書き出し設定

共通の条件：

- 範囲：小節1から決めた固定長まで（毎回同じ）
- 形式：WAV、48kHz、32bit float、ノーマライズなし、ディザなし
- 中身：インサートエフェクト、ボリューム・パン（オートメーションを含む）込み
- センド系（リバーブなど）：そのトラックのインサートに挿すか、リバーブのバスを別スロットとして書き出す
- ファイル名：`<担当者>_<スロット名>.wav` で上書き保存

### Logic Pro

「ファイル」→「書き出す」→「すべてのトラックをオーディオファイルとして書き出す」（1トラックだけなら「トラックをオーディオファイルとして書き出す」）。

| 設定 | 値 |
| --- | --- |
| 範囲 | 書き出す前に、サイクル範囲を小節1〜固定長の終わりに設定する（またはプロジェクトの終了位置を固定長に合わせる） |
| ファイルの形式 | WAVE |
| ビット深度 | 32ビット浮動小数点 |
| サンプルレート | 48 kHz（プロジェクト設定を48 kHzにしておく） |
| エフェクトプラグインをバイパス | オフ（エフェクト込みにする） |
| ボリューム／パンのオートメーションを含める | オン |
| ノーマライズ | オフ |
| ファイル名 | トラック名をスロット名にしておくと、そのまま使える |

### Studio One

「ソング」→「ステムをエクスポート」。

| 設定 | 値 |
| --- | --- |
| 対象 | 「トラック」または「チャンネル」タブで、自分の担当トラックだけを選ぶ（チャンネル単位ならフェーダー・インサート込み） |
| 範囲 | 「ループ間」を選び、ループ範囲を小節1〜固定長の終わりにしておく |
| 形式 | Wave File、32 Bit Float、48 kHz |
| ファイル名 | チャンネル名をスロット名にしておく（出力名の規則は要確認） |

## 5. 受け側：取り込み設定

共有WAVは、曲頭（小節1）に置いた**曲全体の長さの1クリップ**にして、LiveStem ARA を挿します。そのうえで次の2点が重要です。

### 音声をコピーさせない

DAWがプロジェクトフォルダにコピーすると、コピー側のファイルを参照するようになります。プラグインは共有フォルダを直接読むので鳴る音は正しいままですが、DAWの波形表示とフォールバック時の音が古いコピーのものになります。

- **Logic Pro**：「ファイル」→「プロジェクト設定」→「アセット」で「オーディオファイルをプロジェクトフォルダにコピー」をオフ。
- **Studio One**：ファイルを読み込むときにコピーするかどうかを尋ねられたら「コピーしない」。常にコピーする設定になっていないか「オプション」→「場所」も確認（項目名は要確認）。

### タイムストレッチを無効にする

共有WAVはテンポを合わせて書き出してあるので、DAW側で伸縮させません。

- **Logic Pro**：トラックの Flex をオフ。取り込んだリージョンのインスペクタで「Flexと追従」をオフ。取り込み時にテンポ情報の読み込みを尋ねられたら「読み込まない」。
- **Studio One**：イベントのインスペクタで「テンポに追従」をオフ（タイムストレッチなし）。ファイルにテンポ情報があってもストレッチされないことを確認。

### そのほか

- 受け側のトラック：フェーダー 0dB、パン センター（送る側で音量・パン込みで書き出してあるため）。
- 受け側でクリップをカット・削除・移動・複製するのは自由です。中身だけが最新のWAVに追従します。
- 受け側でカット済みの範囲に送る側が新しい音を入れても、受け側では鳴りません（クリップがないため）。フェーズ2で「変更された範囲」を表示して気づけるようにします。

## 6. トラブルシューティング

| 症状 | 確認すること |
| --- | --- |
| 状態が「ファイルなし」 | パスが正しいか。Syncthing の同期が終わっているか |
| 状態が「エラー」 | 画面のメッセージを確認。WAV以外の形式、書き出しの途中で止まったファイルなど。直前の内容が鳴り続けます |
| 「サンプルレートが違う」警告 | 送る側の書き出しを48kHzにする（フェーズ1では元の音声を鳴らします） |
| 「長さが元のクリップと違う」注意 | 書き出し範囲の固定長が両者で一致しているか |
| 更新されない | Syncthing の画面で同期済みか。プラグイン画面の「最終読み込み」時刻が変わっているか |
