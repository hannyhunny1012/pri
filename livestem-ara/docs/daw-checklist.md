# DAW手動確認チェックリスト

フェーズ1の検証項目を、Logic Pro と Studio One の実機で確認するための手順です。フェーズ2の完了時にも同じ手順で再確認します。

結果は各項目の表に ○（できた）／×（できない）／△（条件付き）で記入し、気づいたことをメモ欄に書いてください。

## 準備

1. プラグインをインストールする（[README](../README.md#インストール先)）。macOS ではアドホック署名をし直す。
2. テスト用フォルダ（例：`~/LiveStemTest/`）を作る。
3. 48kHz・32bit float・ステレオのテスト用WAVを3つ用意する。どれも同じ長さ（例：60秒）にする。
   - `A.wav`：はっきり区別できる音（例：1小節ごとのクリック）
   - `B.wav`：別の音（例：持続するサイン波）
   - `C.wav`：さらに別の音（例：ドラムループ）
4. `A.wav` を `bob_test.wav` という名前でテスト用フォルダにコピーする。
5. 48kHzの新規プロジェクト（120 BPM 固定）を作り、`bob_test.wav` を小節1に置く（コピーしない、タイムストレッチなし）。
6. そのトラックに LiveStem ARA を ARA として挿し、画面で `bob_test.wav` を選ぶ。状態が「最新」になることを確認する。

ファイルの差し替えは、Finder／エクスプローラーで `B.wav` を `bob_test.wav` という名前で上書きコピーして行います。

### 3. クリップのカット・削除・移動・複製が出力に反映されるか

手順：
- カット：クリップを3つに分け、真ん中を削除 → その範囲が無音になるか。
- 移動：分けた後半を2小節後ろへ動かす → 動かした位置で鳴るか。
- 複製：前半を複製して別の位置に置く → 複製先でも同じ音が鳴るか。
- 編集後に差し替える → 編集したすべてのクリップが新しい内容になるか。

### 8. 新しいWAVが元より短い／長い場合の挙動

手順：
