## 実装上の判断（フェーズ2で見直す可能性があるもの）

1. **差し替えの単位**：音声ソース（DAWが取り込んだファイル）ごとに共有WAVを1つ対応付けます。同じソースを使うクリップ（分割・複製したもの）はすべて同じファイルに追従します。
2. **ファイルが消えたとき**：一度読み込んだあとに消えた場合は、直前の内容を鳴らし続けます（Syncthing の置き換え中や一時的な削除で音が途切れないようにするため）。最初から見つからない場合は、DAWの元の音声を鳴らします。
3. **差し替えの瞬間**：クロスフェードはしていません。実機で段差のクリックが気になるようなら、フェーズ2で数ms のクロスフェードを入れます。
4. **プロジェクトを開いた直後**：保存されていたパスを復元し、ファイルを読み込み終わるまで（約0.5〜1秒）はDAWの元の音声を鳴らします。
5. **ホストへの通知**：ファイルの読み込み後に「内容が変わった」通知を送ります。DAWによっては、これでプロジェクトが「変更あり」扱いになる可能性があります（チェックリストの追加項目で確認）。
